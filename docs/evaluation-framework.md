# 평가 기준과 가중치

## 계산 방식

각 세부 항목에 프로젝트별 평점 1~5를 부여하고, 항목 중요도 1~5를 곱해 합산합니다.

```text
가중 총점 = Σ(프로젝트 평점 × 항목 중요도)
```

점수는 실제 성능 측정값이 아니라 주제 선정 토론을 위한 초안입니다. 최종 결정 전에는 핵심 불확실성을 작은 실험으로 검증해야 합니다.

## 배점 근거

- 문제 해결·개선에 가장 높은 5점을 부여했습니다. 결과가 처음부터 완벽한지보다 실패를 측정하고 원인을 찾아 개선하는 과정이 AI·OSS 역량을 더 잘 보여주기 때문입니다.
- 개발 기간 적합성도 5점입니다. 시연 가능한 통합 결과물이 없으면 다른 강점을 검증하기 어렵습니다.
- AI와 OSS는 각각 20점으로 균형을 맞췄습니다. 모델 호출이나 라이브러리 설치만으로 끝나지 않고 실제 사용자 흐름과 개선 기록으로 연결돼야 합니다.
- 디자인, 서비스 가치, 시연성, 팀 역량은 각각 10점입니다. 중요한 요소지만 핵심 기술의 증거를 대신하지 않도록 균형 가중치를 적용했습니다.
