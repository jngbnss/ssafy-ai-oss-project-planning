# 팀 회의 안건

## 주제 선택 전에 합의할 내용

- [ ] AI가 없으면 해결하기 어려운 핵심 사용자 흐름은 무엇인가?
- [ ] 1~2주 안에 검증 가능한 최소 데모는 무엇인가?
- [ ] 가장 큰 기술적 불확실성 한 가지는 무엇인가?
- [ ] 비교할 AI 모델과 베이스라인은 무엇인가?
- [ ] 품질을 어떤 데이터와 수치로 측정할 것인가?
- [ ] OSS 라이선스와 상업·배포 가능 범위를 확인했는가?
- [ ] OSS 내부에서 분석·개선하거나 별도 모듈로 공개할 부분이 있는가?
- [ ] GPU, 센서, 게임패드 등 필요한 인프라를 확보할 수 있는가?
- [ ] 실패했을 때 사용할 대체 모델이나 축소 경로가 있는가?
- [ ] 7명의 역할이 중복되지 않고 하나의 데모로 통합되는가?

## 후보별 첫 검증 실험

| ID | 첫 실험 |
|---|---|
| P1 | 고정 발화 20개로 WER와 음성 왕복 지연 측정 |
| P2 | 동일 사건에 적대적 질문 100개를 입력해 비밀 누설률 측정 |
| P3 | 질문 50개에 대해 제시된 원문 근거가 실제 존재하는지 검수 |
| P4 | 제스처 3종을 300회 수행해 혼동행렬과 지연 측정 |
| P5 | 서로 다른 그림 20장으로 메시 생성과 리깅 성공률 분리 측정 |
| P6 | 동일 맵 30회에서 행동 트리와 학습 정책의 생존율 비교 |
| P7 | 작업 시나리오 20개에서 위험 탐지 재현율과 오경보율 측정 |
| P8 | 동일 서킷 30회에서 규칙 AI와 학습 정책의 완주율·충돌률 비교 |

## 회의 종료 조건

1. 1순위 후보와 예비 후보를 각각 하나 정합니다.
2. 선택한 후보의 1주 차 검증 실험과 담당자를 정합니다.
3. 성공·실패 판정에 사용할 최소 수치를 정합니다.
4. 실험 결과를 기록할 문서와 다음 의사결정 날짜를 정합니다.
