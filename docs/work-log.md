# 작업 및 결정 기록

## 2026-10-10 · 초기 기획 정리

- SSAFY 3차 프로젝트를 위한 AI·OSS 후보 8개와 평가 기준 28개를 정리했습니다.
- 모델을 직접 학습하는 것만이 아니라 적절한 모델의 탐색·선택·연결·평가·개선 과정도 AI 역량으로 정의했습니다.
- OSS는 설치 여부보다 라이선스 검토, 내부 구조 이해, 통합, 개선 및 재기여 가능성을 중심으로 보기로 했습니다.
- 주제 확정 전에는 바로 구현하지 않고 오피스아워 방식으로 MVP, 위험, 측정 지표를 검토하기로 했습니다.

## 2026-10-10 · 인터랙티브 발표 자료 제작

- HTML, CSS, JavaScript 기반의 PPT형 발표 자료를 제작했습니다.
- 첫 장은 `3차 프로젝트 설계 도메인 보고서`라는 제목만 남겨 간결하게 구성했습니다.
- 두 번째 장은 AI·OSS 역량을 `적절한 모델과 OSS를 찾아 연결하고, 측정하며 개선하는 능력`으로 요약했습니다.
- 평가 기준 장표에는 28개 세부 항목, 가중치, 배점 근거를 표시했습니다.
- 프로젝트 목록 장표에는 8개 후보의 개요를 넣고 카드에 마우스를 올리면 SWOT이 나타나도록 구현했습니다.
- 평가 점수와 한 줄 총평 뒤에 점수 순서대로 프로젝트 상세 장표를 배치했습니다.

## 2026-10-10 · 후보 구성 변경

- 전략 최적화 게임 후보는 전체 보고서에서 제거했습니다.
- 쥬라기 생태계와 디지털 트윈의 번호를 각각 P6, P7로 조정했습니다.
- 기존 브라우저 레이싱 게임을 P8 `AI 레이싱 게임 + 주행 에이전트` 후보로 추가했습니다.
- 모든 목록, 점수, 순위, 상세 설명 및 장표 번호를 새로운 8개 구성에 맞춰 다시 정리했습니다.

## 2026-10-11 · 데모와 저장소 연결

- 프로젝트 상세 장표의 버튼 문구를 `데모 확인하기`로 통일했습니다.
- P1~P8 모두 각 프로젝트의 공개 GitHub Pages 주소로 연결됩니다.
- 브라우저 프론트엔드가 아직 없는 프로젝트는 현재 구현 단계와 저장소 링크를 보여주는 공개 안내 페이지로 연결됩니다.
- P8은 [배포된 레이싱 게임](https://jngbnss.github.io/f1/)으로 연결됩니다.
- 프로젝트별 GitHub 저장소명을 각 상세 장표의 실행 버튼에 표시했습니다.
- CSS, JavaScript, 이미지가 모두 포함된 단일 `index.html`로 패키징해 다른 컴퓨터에서도 별도 설치 없이 확인할 수 있도록 했습니다.

## 발표 자료 범위

- 발표 속 콘셉트 이미지는 목표 경험을 보여주는 시각 자료이며 구현 완료 증거가 아닙니다.
- `100% MVP`는 작은 범위에서 실제 검증할 기능을 뜻합니다.
- `120% 목표 경험`은 현실적인 MVP보다 시각적 연출과 설명력을 약 20% 높인 목표 데모를 뜻합니다.
- 현재 점수는 팀 합의를 위한 상대 평가이며, 실험 결과가 나오면 변경할 수 있습니다.
